              Voice Command Reference

              Speak naturally into your microphone. Memoir listens for structural intent cues to automatically organize your knowledge graph:

              "Chapter [Title/Number]" / "New Chapter [Title]"
              Creates a new top-level Chapter markdown file (.md) and sets it as the active chapter.
              "Topic [Title/Number]" / "New Topic [Title]"
              Creates a Topic markdown file automatically linked to the active Chapter with [[Chapter]].
              "Thought [Text/Idea]" / "New Thought [Text]"
              Creates an atomic Thought note linked to the active Topic/Chapter and discovers related thoughts.
              "Append to chapter [Text]" / "Append to chapter 1 [Text]"
              Appends spoken text (or the reviewed transcription) to the specified or active Chapter as a new paragraph.
              "Append to topic [Text]" / "Append to topic"
              Appends spoken text to the active/most recent Topic note.
              "Append to thought [Text]" / "Append to thought"
              Appends spoken text to the active/most recent Thought note.
              "Save transcription" / "Accept"
              Appends the reviewed transcription buffer into the current document hands-free.
              "Discard" / "Cancel" / "Clear"
              Clears the current transcription buffer hands-free.
              "Link to [Note Name]"
              Inserts a bi-directional [[Note Name]] wikilink directly into the active document.
              "Tag [Keyword]"
              Adds a #keyword tag to the current document.
              "New line" / "New paragraph" / "Bullet point ..."
              Controls line breaks, paragraphs, and list items seamlessly during voice flow.
              "Pause recording" / "Stop transcription"
              Toggles the microphone off hands-free.
